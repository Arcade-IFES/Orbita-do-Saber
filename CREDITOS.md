# Créditos

## Autoria

Projeto educativo **Órbita do Saber — Mulheres que transformaram o mundo**.

- Conceito, interface e programação: equipe Órbita do Saber.
- Banco de questões: elaborado para este projeto, com revisão de redação e indicação de fontes públicas.
- Imagem de capa: criada especialmente para este jogo, sem uso de imagem de terceiros.

## Fontes de pesquisa

As fontes consultadas aparecem individualmente no campo `fonte` de cada questão em `questoes.json`. São páginas institucionais, museus, universidades, órgãos públicos e organizações responsáveis por prêmios ou acervos.

Material destinado a atividades educacionais. Preserve esta declaração de autoria e os links das fontes ao redistribuir o jogo.
